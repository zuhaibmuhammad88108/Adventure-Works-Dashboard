# AdventureWorks Business Intelligence Dashboard
An end-to-end multi-page Power BI project built using the classic AdventureWorks dataset. This dashboard provides deep analytical visibility into executive performance, product-level scenarios, customer segmentation, and global distribution.

## 📌 Project Overview
The goal of this project was to transform raw business data into actionable, interactive insights. The solution features a modern dark-mode aesthetic and is split into multiple specialized views to cater to different analytical needs—from high-level executive summaries to granular product pricing simulations and customer behavior metrics.


## 🚀 Key Features & Dashboard Pages

### 1. Executive Summary
 * **High-Level KPIs:** Tracks total revenue (**$24.9M**), total profit (**$10.5M**), total orders (**25.2K**), and overall return rates (**2.2%**).
 * **Revenue Trending:** Visualizes historical growth over time alongside monthly revenue, orders, and returns metrics with month-over-month comparisons.
 * **Product Rankings:** Spotlights top-performing categories (Accessories, Bikes, Clothing) and lists top products alongside return percentages.
 
### 2. Product-Level Deep Dive & What-If Analysis
 * **Dynamic Simulations:** Features a price adjustment slider allowing users to simulate price changes and analyze the subsequent impact on profit and revenue.
 * **Target Gauges:** Compares actual monthly orders, revenue, and profit against targets for individual items (e.g., *Water Bottle - 30 oz.*).
 * **Automated Insights:** Built-in report summaries highlighting trend changes and growth percentages for selected items.
 
### 3. Customer Demographics & Behavior
 * **Customer Metrics:** Monitors unique customer counts and average revenue per customer.
 * **Segmentation:** Breaks down orders by income levels (High, Average, Low) and occupations (Management, Skilled Manual, Professional).
 * **Top Customers Leaderboard:** Displays top revenue-generating customers and tracks specific ordering patterns.
 
### 4. Global Footprint
 * **Interactive Mapping:** Utilizes geographic visual tools to monitor regional sales performance across North America, Europe, and the Pacific.
 
## 🛠️ Tech Stack & Tools
 * **Data Visualization & Modeling:** Microsoft Power BI
 * **Data Processing & Measures:** DAX (Data Analysis Expressions)
 * **Design:** Custom dark UX/UI theme optimization
